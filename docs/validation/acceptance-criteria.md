# Acceptance and Definition of Done

## Definition of Ready

A feature is ready to build only when:

- its product outcome and non-goals are documented;
- inputs, outputs, failure behaviour, and acceptance criteria are explicit;
- every threshold it uses exists in the ASTA rules catalogue;
- validation scenarios are written; and
- no open decision would materially change its design.

## Definition of Done

A feature is done only when:

- the approved specification is implemented;
- automated tests cover every validation scenario;
- failure states are visible and safe;
- profit and loss do not affect any score it produces;
- documentation and the roadmap status are updated; and
- known limitations are recorded.

## Evidence required

For each completed feature, retain the specification, test results, and a short verification note in `docs/validation/`.
