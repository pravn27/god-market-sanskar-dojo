# ASTA glossary

| Term | Meaning in this app |
| --- | --- |
| ASTA | Avadhut Sathe Trading Academy process the app enforces |
| God Market | The market treated with gratitude and respect; outcome is not in the trader's control |
| Sanskar | Character built through repeated daily practice |
| Dojo | The daily practice space: rituals, oath, and preparation |
| Brick size | Capital unit allocated for the week |
| Risk band | Allowed rupee risk per trade for the week (default 1,000 to 3,000) |
| Weapon candle | The confirming candle a setup requires before entry |
| Grade A / F | Process grade for a trade: A followed the stop-loss rules; F did not |
| Quadrants | Good Profit, Good Loss, Bad Profit, Bad Loss: grade combined with result |
| Discipline % | Grade-A trades divided by total trades for a market day |
| Red Zone | Discipline below 70%; Trade Gate locked for 2 market days |
| Capital lock | 50% maximum position size after a Grade F until 3 clean days |
| Readiness | Morning preparation score; 80 or more unlocks the Trade Gate |
| Season | A fixed challenge, for example 50 trades at 500 risk with a 25,000 loss budget |
| Five roles | Opportunity Hunter, Opportunity Converter, Risk Manager, Money Manager, Reviewer and Auditor |
| Full GEO | ASTA technical-analysis syllabus: SMM, PAPA, GUE (Elliott wave), FOME, and related modules |
| Triple Screen / Double Screen | SMM multi-timeframe decision methods |
| Market day | NSE trading day: Monday to Friday excluding listed holidays |
